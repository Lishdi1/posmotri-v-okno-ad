# Посмотри в окно

Учебный проект Яндекс Практикума. Интерактивная страница, где можно «посмотреть в окно» разных городов: выбрать видео из списка, отфильтровать по городу и времени суток.

## Функциональность
- Загрузка списка видео с внешнего API и вывод карточек
- Переключение основного видео по клику на карточку
- Поиск по городу и фильтр по времени суток (утро / день / ночь)
- Подгрузка дополнительных карточек кнопкой «Показать ещё»
- Прелоадеры во время загрузки и заглушки при ошибках

## Технологии
- Семантический HTML5
- CSS3: флексбокс-раскладка, кастомные состояния форм, object-fit, псевдоэлементы
- Вёрстка по макету (пиксель-перфект)
